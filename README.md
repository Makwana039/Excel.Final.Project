# 📊 Data Intelligence Dashboard – Excel Final Project

An interactive **Data Intelligence Dashboard** built using Microsoft Excel to analyze customer transactions, sales performance, profitability, customer behavior, and business trends.

This project demonstrates practical skills in **Data Analysis, Advanced Excel, Statistical Analysis, Data Visualization, and Business Intelligence**.

---

## 📌 Project Overview

**Project Name:** Data Intelligence Dashboard  
**Tool:** Microsoft Excel 2013  
**Project Type:** Data Analytics & Business Intelligence  
**Dataset:** Customer Transaction Dataset (200+ Records)

### 🎯 Objective

The main objective of this project is to transform raw customer transaction data into meaningful business insights using Excel formulas, PivotTables, statistical analysis, and interactive dashboards.

## 📂 Project Structure

The workbook contains the following major sections:

1. **Final Project Dataset** – Raw customer transaction data.
2. **Data Analysis** – Calculations, formulas, and business analysis.
3. **Customer Analysis** – Top 10 customers by revenue and orders.
4. **Product Analysis** – Product-wise revenue and profit.
5. **Category Analysis** – Category-wise sales performance.
6. **Region Analysis** – Region-wise sales performance.
7. **City Analysis** – City-wise sales performance.
8. **Sales Channel Analysis** – Performance by sales channel.
9. **Payment Analysis** – Payment method distribution.
10. **Delivery Analysis** – Delivery status analysis.
11. **Order Analysis** – Order status analysis.
12. **Statistical Analysis** – Descriptive statistics and regression analysis.
13. **Dashboard** – Interactive business intelligence dashboard.

## 📈 Key Performance Indicators (KPIs)

The dashboard tracks important business performance indicators:

| KPI | Description |
|---|---|
| Total Revenue | Overall revenue generated |
| Total Profit | Overall profit earned |
| Total Orders | Total number of orders |
| Quantity Sold | Total units sold |
| Average Order Value | Average revenue per order |
| Average Profit | Average profit per order |
